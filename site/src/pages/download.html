Verify what you downloaded

Compare the checksum with the table above{{#if release.hasSums}} (it comes from the SHA256SUMS.txt file published with the release){{/if}}:

{{#each release.arches}}{{#if dmg}}
shasum -a 256 ~/Downloads/{{dmg.name}}
{{/if}}{{/each}}

Open the disk image, drag OpenTac to Applications, then check the signature and Apple's notarization:

codesign --verify --deep --strict --verbose=2 /Applications/OpenTac.app
spctl -a -vv /Applications/OpenTac.app
xcrun stapler validate /Applications/OpenTac.app

A good result says accepted and source=Notarized Developer ID. If any of these fails, do not run the app; download it again, and if it still fails, tell us.

Verifying downloads

When the first release is out, this page lists a SHA-256 checksum for every file. Compare it with shasum -a 256 <file>, then check the app after installing:

codesign --verify --deep --strict --verbose=2 /Applications/OpenTac.app
spctl -a -vv /Applications/OpenTac.app
xcrun stapler validate /Applications/OpenTac.app

A good result says accepted and source=Notarized Developer ID.

Older releases

Every release, including older versions, is on GitHub Releases. OpenTac also updates itself: the app checks for new versions and the engine checks for new God's Eye View code, and both ask before changing anything. See the changelog.
