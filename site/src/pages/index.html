Free and non-commercial. Needs macOS 13.5 or later (Apple Silicon or Intel). No API keys required to start.

OpenTac is an unofficial macOS app for God's Eye View, the open-source real-time globe created by Bilawal Sidhu. All the magic is his; OpenTac just makes it a double-click.

  • God's Eye View on GitHub
  • Bilawal Sidhu on YouTube

OpenTac is independent. It is not endorsed by, affiliated with, or supported by the upstream author. Questions or bugs about the globe itself belong in the upstream repository; problems with the Mac app or its installer belong in the OpenTac repository.

What you get

  • The live world on one globe

    Aircraft, satellites, earthquakes, public cameras and launches work with no keys at all. Ships and fires switch on with free keys you add yourself.

  • Voice control

    Talk to the globe. Voice uses OpenAI or Gemini and your own key; nothing is sent until you turn it on. AI options

  • Photorealistic 3D with your own keys

    Add a Cesium ion token or a Google Maps key for photorealistic cities. Keys stay on your Mac. Which key unlocks what

  • A self-updating engine

    The globe's code updates in place from GitHub, only after you have read what changes and confirmed it. A failed update rolls back.

How it works

  1. A runtime in the box

    OpenTac carries its own Node.js, so there is nothing to install and nothing on your PATH is touched.

  2. A live checkout from GitHub

    On first launch it fetches the God's Eye View code, installs its dependencies and starts it on 127.0.0.1. That takes a few minutes and needs internet.

  3. Updates with full disclosure

    OpenTac shows what changed before anything is applied, asks you to confirm, and keeps the previous version to roll back to.

System requirements

  • macOS 13.5 or later, on Apple Silicon or Intel.
  • About 1 GB of disk after the first run; the installer wants at least 2 GB free.
  • An internet connection for the first run, for updates, and for the live data itself.
  • A Mac with working WebGL (any Mac that runs macOS 13.5 qualifies).

Questions

Is this the official God's Eye View app?

No. God's Eye View is made by Bilawal Sidhu. OpenTac is an independent, unofficial wrapper that makes it a double-click on a Mac. He has not endorsed it and does not support it.

Do I need API keys?

No. It starts with no keys. Keys are optional extras for photorealistic 3D, ships, fires, traffic and voice. See Keys.

Is it safe to open? Will macOS warn me?
{{#if release.available}}

Release builds are signed with a Developer ID and notarized by Apple, so the usual first-open prompt is all you should see. You can check the signature and the checksum yourself; the steps are on the download page.

{{else}}

There is no release to open yet. Releases are meant to be signed with a Developer ID and notarized by Apple; once one is published, the download page lists the signature, notarization and checksum checks so you can confirm it yourself.

{{/if}}

What does it send over the network?

No telemetry, no accounts. It talks to GitHub for the engine and its own updates, and the globe fetches live data from the providers God's Eye View uses. Details are on the privacy page.

How do engine updates reach me?

OpenTac follows a stable channel on its own mirror of the upstream code. New upstream commits are pulled in weekly, tested automatically, and wait several days before they are promoted to stable. You are always shown the change and asked first.

Windows or Linux?

OpenTac is macOS only. God's Eye View itself runs elsewhere; see its README.

Can I use it commercially?

OpenTac is distributed as a non-commercial project, because some data bundled with God's Eye View is licensed for non-commercial use only. Read the licenses page before using it for anything commercial.
