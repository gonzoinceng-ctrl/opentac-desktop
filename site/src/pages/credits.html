Credits

God's Eye View, by Bilawal Sidhu

Everything you see on the globe is his work: the real-time globe, the layers, the voice control, the cockpit view. OpenTac is only the wrapper that packages it for the Mac.

  • God's Eye View on GitHub (MIT)
  • Bilawal Sidhu on YouTube

OpenTac is unofficial and is not endorsed by, affiliated with, or supported by him.

Software OpenTac is built on

  • Electron, which brings Chromium
  • Node.js, bundled as the engine's runtime
  • git, by way of dugite
  • CesiumJS, the 3D globe engine used by God's Eye View

Maps and data

  • OpenStreetMap contributors (ODbL), a fallback map and the source of several mapped layers.
  • Esri World Imagery, the default satellite imagery.
  • Google, Cesium ion, OpenSky, adsb.lol, AISStream, CelesTrak, USGS, NASA FIRMS, TomTom, Mapillary, TeleGeography and the others that supply live and bundled data. God's Eye View keeps the authoritative list with each source's license and attribution: DATA_SOURCES.md.

Third-party data is not covered by the MIT license; see Licenses.
