        Troubleshooting
        
          
        
            
          
        
        
        

        
        
          
        Engine updates
        
          
        
            Which engine versions should OpenTac follow?
            
            
            
          
        
          
        
          
        Changing the channel checks for an update straight away. Moving to an older version asks you to reset the engine files first.
        
          
          
        Engine updates are never applied without showing you what changes first. How often the automatic check runs is set under App settings.
        
          
        
            
          
        
          
        OpenTac app updates
        
          
        Updates to OpenTac itself are separate from engine updates.
        
          
        
            
          
        
          
        
        
        

        
        
          
        Engine API keys
        
          
        
          
        These are saved by the engine itself in its own .env file, on this Mac only, readable only by you. Every key is optional.
        
          
        Saving a key makes the engine restart itself and reload the page. That is expected, not a crash.
        
          
        
          
        
          
          
          
          
            Advanced keys
            
            
          
            

          
            Summary provider keys
            
          
            Encryption is unavailable on this Mac right now, so OpenTac cannot store API keys. Ollama and OpenAI still work.
            
          
            These two keys are for the optional summary providers in the AI summaries tab. OpenTac keeps them encrypted in its own data folder, never in the engine’s .env file.
            
          
            
            
            
            
              
              
              
            
            
            
            
          
            
          
            
            
            
            
              
              
              
            
            
            
            
          
            
        
            

        
            
          
            This only changes the provider for the short summary line in the engine’s heads-up display. OpenRouter and xAI keys are entered under API keys.
            

          
            
            
            
          
            
          
            OpenAI summaries are sent by the engine itself, so there is no model to pick here. Its model is under Engine settings.
            
          
            
            
            
            
            
            Leave empty to use the provider’s default.
            
          
            
          
            
            
            
            
            
              
            
            
            
            
            
            Models are loaded from the address that is saved, so save your settings first after changing it.
            
          
            

          
            Saving a different provider restarts the engine.
