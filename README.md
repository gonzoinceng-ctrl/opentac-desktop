# OpenTac

Unofficial macOS desktop app for **God's Eye View**, the open-source real-time
globe by [Bilawal Sidhu](https://github.com/bilawalsidhu/gods-eye-view) (MIT).
OpenTac bundles a Node runtime, keeps a live checkout of the upstream project
in your Application Support folder, and updates it from GitHub with full
disclosure. Not affiliated with or endorsed by the upstream author.

See `docs/brief/` for the build brief. Quick start:

```
npm ci && npm run fetch-node && npm run dev
```
